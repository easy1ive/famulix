# Security Policy

## Reporting a vulnerability

If you find a security issue in famulix, please email the maintainer at
239626936+easy1ive@users.noreply.github.com rather than opening a public issue.

We will acknowledge the report within a reasonable timeframe and work with you
to verify and address the issue.

## Scope

This project is an offline framework for personal memory research. It does not
connect to network services by default and does not ship with pretrained
models. Security issues related to data handling, privacy semantics, or
deletion correctness are in scope.
