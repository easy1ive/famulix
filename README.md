# famulix

离线个人 agent 框架，核心是长期记忆与个性化，附带一个确定性的每日简报应用。

## 特性

- 长期记忆图：节点与类型化边，支持来源追踪与版本化
- 编码、合并、衰退流水线：事件→片段→事实→偏好→提醒
- 混合检索：BM25 + 近新度 + 重要度融合，MMR 多样性重排
- 上下文组装：0/1 背包 DP，严格预算遵守
- 偏好学习：显式评分与隐式反馈，Brier 校准度量
- 隐私与删除语义：PII 检测、分级访问、可审计的遗忘权
- 计划 DSL 与策略门控执行器
- 确定性会话记录与回放
- 每日简报应用：自包含 HTML + SVG，每条信息引用记忆来源
- 完全离线：合成个人历史工厂，所有指标来自可控实验

## 安装

```bash
pip install famulix
# 可选 PyTorch 额外能力（CPU-only）
pip install "famulix[torch]" --extra-index-url https://download.pytorch.org/whl/cpu
```

## 快速开始

```bash
famulix demo
```
