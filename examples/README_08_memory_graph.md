# Example 08: Memory Graph

Demonstrates building and querying a memory graph.

## Running

```bash
python examples/08_memory_graph_demo.py
```

## Expected Output

- Memory graph summary
- Node and edge counts
- Node kind distribution

## Key Concepts

- Memory nodes (facts, preferences, episodes)
- Memory edges (mentions, part_of, derived_from)
- Graph invariants (no dangling edges, acyclic provenance)
